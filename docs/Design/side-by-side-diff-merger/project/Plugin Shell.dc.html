DevTools 3: plugin-based shell

Two layout directions, dark theme. Each row is the same screen in both. Built-in tools stay built in; new tools are plugins (web UI, optional WASM backend) from repositories, zip files, folders or repo URLs. Permissions are declared and approved by the user; packages are checked by SHA-256.

1a

Sidebar

Keeps today’s sidebar. Installed tools are grouped by category, and Plugins is a sidebar destination with an update badge. Browsing uses a list with a detail pane.
