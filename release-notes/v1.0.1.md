# Shard v1.0.1

## Highlights

- Dropping a file on Shard no longer replaces the app with the system's PDF viewer. Files dropped outside a drop area are ignored.
- Plugin zips can be dropped on the Install plugin drop area on Linux. Before, the drop was rejected as "Drop a plugin .zip file." even for a valid zip.

## App Updates

- A plugin zip dropped anywhere else shows a hint that points to Install plugin, with an Open button.
- On Linux the window now takes file drops natively, so a zip dragged from a file manager arrives with its real path. Windows and macOS keep their existing drop handling.
- Shard blocks the main window from navigating to local files, as a second line of defence against stray drops.
- Plugin frames ignore files dropped outside their own drop areas. Installed plugins pick this up when they are rebuilt with the new plugin SDK.
- Drops onto the Diff & Merge panes and onto plugin frames do nothing on Linux for now. They never worked there.
