# Shard v2.8.0

## Highlights

- New tool: Diff & Merge. Compare two texts side by side and move changes across with one click, the way you do in a JetBrains IDE.
- Compare two folders in the desktop app, choose what to do with each file, and merge them in one step. Shard backs up the files it replaces, and you can undo the merge.

## New Tools

- Diff & Merge shows two editable panes joined by curved bands. Click `>>` or `<<` next to a change to copy it to the other side. Ctrl-click appends it instead of replacing. Ctrl+Z undoes.
- Highlight changes by word, line, or character. Ignore whitespace, trim lines, ignore case, or ignore empty lines.
- Move between changes with F7 and Shift+F7. Collapse unchanged lines, switch to a unified view with Keep buttons, and sync the scrolling of both panes.
- Open or drop a file into either pane, paste text, or swap the sides. The language is detected from the file name or the content. Copy or save the result with its original line endings, and save a patch from the unified view.
- Folders mode (desktop app only) compares two folders by content, by size and date, or by size. Show or hide left-only, right-only, different, and identical files, and filter by name or path.
- Set an action per file: copy left to right, copy right to left, ignore, or decide later. Select several files to change them together. Start merge lists everything before it writes anything.
- Open a file that differs on both sides in a line-by-line diff below the list, then save both sides or open the pair in Text mode.
- After a merge, Undo merge puts the files back, and Show backup opens the backup folder.

## App Updates

- Folder compare never reads or writes outside the two folders you choose. It does not follow links that point elsewhere.
- Everything runs on your machine. Nothing is uploaded.
