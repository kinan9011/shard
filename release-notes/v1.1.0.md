# Shard v1.1.0

## Highlights

- Shard is now available in eight languages: English, German, Arabic, French, Spanish, Chinese, Japanese and Hebrew. Arabic and Hebrew switch the whole app to right-to-left.
- The app has a new look, modeled on the JetBrains New UI: flat surfaces, a tool stripe, a Tools tree sidebar, a tab row and a status bar. Inter and JetBrains Mono are bundled, so it looks the same offline.
- You can choose the font for the app and for fields and editors, set a field size and zoom the whole UI. You can also add your own font files.
- Shard remembers your open tabs and what you typed in each tool, so a restart picks up where you left off.

## Tool Improvements

- Send to…: a tool's output can be sent to another tool that recognizes it, such as JSON to a JSON tool or a JWT to a JWT decoder. The other tool opens with the text already in its input.
- Code and JSON fields always stay left-to-right, even in an RTL app. Text fields follow the direction you type, and Text Compare has a direction toggle. A shortcut flips the direction of the focused field.
- Diff & Merge panes stay left-to-right and set the direction of each line, so mixed Arabic or Hebrew and English text reads correctly.

## App Updates

- Pick the language in Settings or in the first-run wizard. The tray menu follows it too.
- Settings now opens on General instead of Appearance.
- Settings > Appearance has new pickers for the app font, the field font and size, and zoom. Uploaded fonts are stored on your device and included in the settings backup.
- Settings has a "Remember tool inputs" switch. Secrets and keys are never kept. Turning it off erases what was saved.
- The new default dark and light themes keep text and controls at readable contrast. Other schemes and custom themes keep working.
- On a phone, the drawer now ends with Plugins, Settings and the status line.

## For Plugin Authors

- New SDK calls: `shard.locale.get()` and `shard.locale.onChange()` give the app language and direction, and `shard.onInput()` receives text sent from another tool or pasted. Neither needs a permission. Rebuild with the new SDK to use them.
- Plugins now receive the new surface, solid accent and dialog shadow colors (`--primary-solid`, `--surface-hover`, `--surface-selected`, `--shadow-dialog`), so they can match the new look.
