# Shard v1.0.0

## Highlights

- Shard now has plugins. Install tools from the new Plugins page, from a repository, a zip file, a folder, or a GitHub URL. Each plugin shows what it asks for, and you approve it before it runs.
- Plugins run in a sandbox. They cannot read your files, your clipboard, or the network unless you allow it, and they cannot reach the app itself.
- A first-run setup helps new users choose a layout, install starter plugins, and pin tools to Home. Choose between the Sidebar and the new Launcher layout, and change it later in Settings.
- Five tools are plugins now: Hash Generator, UUID Generator, Cron Calculator, Markdown, and Color Palette.

## Plugins

- Open **Plugins** from the sidebar. **Browse** lists plugins from your repositories, **Installed** manages what you have, and **Repositories** adds or removes sources. The official repository is added for you. You can turn it off, but not remove it.
- Every plugin lists its permissions in plain words before you install it: clipboard, files, and network access to named hosts. Optional permissions can be turned off. You can change the permissions of an installed plugin at any time.
- Plugins from a repository are checked against a SHA-256 checksum, and Shard refuses a package that does not match. A zip, a folder, or a URL outside your repositories is not verified. Shard asks you first, and the setting **Allow installs from zip files, folders and URLs outside these repositories** (Plugins → Repositories) controls it.
- A badge on Plugins shows updates. Update one plugin or all of them. Uninstalling removes the plugin's files and the data it stored.
- A plugin that stops responding or hits an error shows "This plugin stopped working" with **Reload** and **Disable**, and does not affect the rest of the app. A plugin tab you are not looking at stays loaded but receives no clicks or focus, and the plugin can pause its work.
- Paste a Hash, UUID, cron, Markdown, or color value, and Shard offers to install the plugin when you do not have it yet.
- Build your own: the [plugin SDK, template, and docs](https://github.com/kinan9011/shard/tree/main/docs/plugins) cover the manifest, permissions, WASM backends, and the build script.

## Layout and Home

- Nine tools are built in and always available: JSON Viewer, Code Playground, Regex Tester, JSON to Code, JSON Schema Validator, JSON Diff, Text Compare, Diff & Merge, and JWT Decoder. You can hide them, but not uninstall them. The other built-in tools stay built in for now.
- Pin up to 12 tools to Home, and reorder them with the mouse or the keyboard. Pinned tools replace Favorites.
- The new Launcher layout puts open tools and search in a top bar instead of the sidebar. Switch layouts in **Settings → Appearance**.
- **Settings** is a page now, with Appearance, General, Shortcuts, Plugins, and About.

## Coming from DevTools

- If you used Hash Generator, UUID Generator, Cron Calculator, Markdown, or Color Palette, Home shows a banner with one-click **Install**. Your pins, open tabs, and recent entries come back as soon as the plugin is installed.
- If you used DevTools before, you see a short "Plugins are here" note instead of the setup.

## Known limits

- The check that keeps plugin frames away from the app's internals ran on Linux. It has not been run on Windows or macOS yet, and the first builds there are the first test.
- A plugin that may reach the network can be sent to a host name that resolves to an address on your own network. Only grant `network` to plugins you trust, and check the hosts they ask for.
- Images from the web do not show in the Markdown plugin's preview. The plugin's content policy blocks them. Images embedded in the text still show.
- Plugins talk to HTTP and HTTPS only. There is no raw TCP yet.

## App Updates

- Plugin files, the list of installed plugins, and plugin data live in the app's data folder. They stay when you update Shard.
- Everything still runs on your machine. Shard makes no network request for a plugin except to the repositories you added, the packages you install, and the hosts you allow a plugin to reach.
