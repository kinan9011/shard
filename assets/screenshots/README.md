# Screenshots

Drop the images used by the root [README](../../README.md) here. Use PNG, keep the window content free of personal data, and take light and dark shots at the same window size.

| File | Size | What to show |
| --- | --- | --- |
| `hero.png` | about 1600x900 | Main window: JSON Viewer with formatted output and two open tabs, light mode |
| `home-light.png` | about 1200x800 | Home with pinned tools |
| `dark-mode.png` | about 1200x800 | Same view as `hero.png` in dark mode |
| `diff-merge.png` | about 1200x800 | Diff & Merge with merge arrows and word highlights |
| `plugins.png` | about 1200x800 | Plugins page, Browse tab |
| `plugin-permissions.png` | about 900x700 | Permission prompt shown before a plugin installs |
| `command-palette.png` | about 1200x800 | Command palette (Ctrl/Cmd+K) with a search term |
| `first-run.png` | about 1000x700 | First-run setup, layout step |
| `launcher.png` | about 1200x800 | Launcher layout |

Do not use the old DevTools images or logo in screenshots.
